# 线上课程参与机制后续更新方案

> **状态：后续规划。** 本文件暂不作为首届线下夏令营的现行规则；待线上课程开放时，再将相关内容同步到仓库首页和正式参与指南。

## 1. 更新目标

在保留线下夏令营任务和答辩机制的基础上，增加纯线上参与路径。线上学习者无需参加线下活动和成果答辩，完成课程学习并提交符合要求且已合入仓库的 PR 后，可获得线上结业证书。

## 2. 参与方式

- **线下学员**：按要求完成小组算子任务并参加成果答辩，可获得夏令营结营证书，并参与优秀项目评选。
- **线上学员**：完成线上课程学习，并至少提交一个符合仓库要求且已合入的 PR，可获得线上结业证书。线上学员不参与本届三个优秀项目奖项的评选。

## 3. 任务要求

学员以小组或个人形式，从届时发布的[候选算子清单](TileKernels-MACA-待迁移算子盘点.md)中选择课题，按照以下流程完成算子泛化、迁移或优化。候选算子主要来源于 [`MetaX-MACA/TileKernels-Metax`](https://github.com/MetaX-MACA/TileKernels-Metax) 的 `dev` 分支，但不会默认开放源仓库中的全部算子：

1. 认领算子并提交或完善 Manifest；
2. 完成或优化 Op、TileLang Kernel、正确性、边界及异常测试；
3. 在真实 MetaX C500 上完成正确性验证、Benchmark、Profiler 和 Roofline 分析；
4. 提交符合仓库要求的实现 PR。

线下学员还须参加成果答辩；线上学员的贡献 PR 须完成 Review 并合入仓库。

## 4. 结业与证书

- 按要求完成线下任务并参加成果答辩的学员，可获得本届开源英才夏令营结营证书。
- 完成线上课程学习且贡献 PR 已合入仓库的学员，可获得线上结业证书。
- 线上结业证书不等同于优秀项目奖项，PR 未合入时不视为完成线上结业要求。

## 5. 优秀项目评选

优秀项目评选仅面向完成任务并参加成果答辩的线下小组。线上学员不参与以下三个奖项的评选：

- 最佳性能优化；
- 最佳工程实践；
- 最佳开源贡献。

## 6. 分支与提交建议

- 线下夏令营继续使用活动指定的 `summer-camp-2026` 分支。
- 线上课程使用仓库开放线上任务时指定的开发分支，不长期依赖临时活动分支。
- 线上贡献同样须遵循算子认领、PR 模板、测试、MetaX C500 验证和 Review 要求。
- 是否达到线上结业要求，以 PR 已合入指定目标分支为准。

## 7. 后续需要同步修改的文件

线上课程正式开放时，至少同步更新以下文件：

1. `README.md`：增加“参与方式”和线上结业证书说明；
2. `README.zh-CN.md`：增加完整的中文线上参与入口；
3. `README.en.md`：补充对应英文说明；
4. `docs/summer-camp/README.zh-CN.md`：明确线下指南与线上路径的适用范围；
5. `docs/summer-camp/README.en.md`：同步英文规则；
6. 算子认领 Issue 和 PR 模板：增加“线下小组 / 线上个人”参与类型。
